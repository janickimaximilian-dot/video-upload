Privacy Policy

Last updated: November 19, 2026

Summary

Video Upload is a personal desktop tool. It only works with the TikTok account of its owner. It does not collect data from anyone else.

Data the tool receives from TikTok

  • an access token and a refresh token, so it can upload videos on the owner's behalf,
  • the account's open_id and display name, to show which account is connected,
  • the granted scopes (user.info.basic, video.upload, video.publish).

How the data is used

The tokens are only used to upload the owner's own videos to the owner's TikTok account and to check the upload status. The display name is only shown to the owner after sign-in.

Where the data is stored

All tokens are stored locally on the owner's computer in a file only the owner can read. Nothing is stored on a server. No data is sold, shared or used for advertising.

Retention and deletion

Tokens are kept until the owner disconnects the tool. Access can be removed at any time in the TikTok app (Settings and privacy, Security, Apps and services). The owner then deletes the local token file.
